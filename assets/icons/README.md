# UI icons

These16icons are from the **Lucide** collection curated on [svgicons.com](https://svgicons.com/icon-set/lucide-svg-icons), by Lucide Contributors. `sources.json` records each exact source page and upstream name. The downloaded bodies are combined into a local SVG symbol sprite; no third-party runtime, CDN or icon package is used.

The source pages identify the collection as ISC. The complete upstream license (including notices for inherited artwork) is preserved in `LICENSE-LUCIDE.txt`, from https://github.com/lucide-icons/lucide/blob/main/LICENSE.

Changes: sprite wrapping, local symbol identifiers and decorative SVG accessibility attributes. Shapes remain as supplied by svgicons.com. Only basic shape/group elements and drawing attributes were accepted; scripts, event attributes and external references are excluded. Application rendering uses a fixed icon-name allowlist.
